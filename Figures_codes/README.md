# RAD51D: running Figures 2A-D, 4A-B, and S3A

Figures 2A-D summarize variant functional scores, genomic coordinates, functional categories, and exon-level categories. Figure 4A shows the amino-acid substitution heatmap. Figure 4B plots the percentage of P strong missense SNVs by amino-acid position, and Figure S3A plots selected structural annotations. Figure 2 and Figure 4A are generated by separate scripts and can be run independently.

## 1. Install the required packages once

Open R or RStudio and paste this into the **Console**:

```r
install.packages(c("readxl", "dplyr", "ggplot2",
                   "ggh4x", "ggbreak", "ragg", "svglite"),
                 repos = "https://cloud.r-project.org")
```


## 2. Select the scripts and workbook

Run these lines **one at a time** in the Console. Each `file.choose()` opens a file-selection window; choose the file indicated by the comment.

```r
source(file.choose())       # Select Figure2.R
source(file.choose())       # Select Figure4A.R
source(file.choose())       # Select Figure4B.R
source(file.choose())       # Select FigureS3A.R
workbook <- file.choose()   # Select the supplementary Excel workbook
sheet <- "S_Data 2"
```

For example, select `Supplementary_information.xlsx` as the workbook. Use the exact worksheet name as it appears in Excel. `Figure2.R` requires the functional-score columns in `S_Data 2`; `Figure4A.R` uses the amino-acid and VarCall category columns, also available in `S_Data 2`. The scripts and workbook do not need to be in the same folder.

Figure 2 requests Arial to match the original default sans-serif font in the Windows plotting environment. Figure 4A requests Calibri, as in the original plot. If a requested font is not installed on the computer generating the plots, R substitutes an available font.

## 3. Generate the figures

Paste this block into the Console:

```r
make_figure2(
  workbook = workbook,
  sheet = sheet,
  output_dir = file.path(dirname(workbook), "Figure2_output"),
  dpi = 600
)

make_figure4a(
  workbook = workbook,
  sheet = sheet,
  output_dir = file.path(dirname(workbook), "Figure4A_output"),
  dpi = 600
)

make_figure4b(
  workbook = workbook,
  sheet = sheet,
  output_dir = file.path(dirname(workbook), "Figure4B_output"),
  dpi = 600
)

make_figure_s3a(
  workbook = workbook,
  sheet = sheet,
  output_dir = file.path(dirname(workbook), "FigureS3A_output"),
  dpi = 600
)
```

Each function can be run on its own when you need only that figure or figure set. Loading a script with `source()` alone does not generate figures.
The plotting functions save files to the specified output folder; they do not display the figures in R's Plot pane.

## 4. Find the results

Four folders are created **beside the selected Excel workbook**:

| Folder | Figure files | Source-data CSV files |
| --- | --- | --- |
| `Figure2_output` | `Figure2A_eta_hist`, `Figure2B_eta_byexon_POS`, `Figure2C_barplot_percentage_all`, and `Figure2D_barplot_percentage_byexon` (each as a DPI-tagged TIFF, e.g. `Figure2A_eta_hist_600dpi.tiff`) | `Figure2_variants.csv`, `Figure2C_counts.csv`, `Figure2D_counts.csv` |
| `Figure4A_output` | `Figure4A_600dpi.tiff` | `Figure4A_heatmap.csv` |
| `Figure4B_output` | `Figure4B_600dpi.tiff`, `Figure4B.svg` | `Figure4B_positions.csv`, `Figure4B_variants.csv`, `Figure4B_domains.csv`, `Figure4B_exons.csv` |
| `FigureS3A_output` | `FigureS3A_600dpi.tiff`, `FigureS3A.svg` | `FigureS3A_points.csv`, `FigureS3A_variants.csv` |

TIFFs use lossless LZW compression at 600 dpi. Figure 2A exports with a white plot and legend background. Figure 4B and Figure S3A also export vector SVG files. The scripts do not write to the input workbook. **Running again with the same output folder replaces the files they generate.**

## Input and troubleshooting notes

The figures use the chosen sheet's VarCall functional categories, not final ACMG classifications. Figures 2A-D and 4A combine start/stop-codon missense records with missense records. Figures 4B and S3A analyze records labeled `missense`; separately labeled start/stop-loss records are not automatically added. When domain or structural-annotation columns are absent, Figures 4B and S3A use their embedded reference annotations.

For **"Missing R packages"**, repeat step 1. For **"A unique variant-table header is required"**, use the function calls above with `sheet` specified, or pass the sheet as the fourth command-line argument after the workbook, output directory, and DPI (for example, `Rscript Figure2.R workbook.xlsx Figure2_output 600 "S_Data 2"` or `Rscript Figure4A.R workbook.xlsx Figure4A_output 600 "S_Data 2"`). For **"Sheet not found"**, check the worksheet name. Stop on other errors rather than bypassing the checks.
